The one-time checklist

  1. Anonymous sign-in — Build → Authentication → Get started → Anonymous → Enable. This is what gives every visitor a stable id so “one vote per person” can be enforced. Without it, nobody can submit or vote.
  2. Google sign-in — same screen, Add new provider → Google → Enable. Only generisdatabase@gmail.com is let into /admin; everyone else is signed straight back out.
  3. Firestore database — Build → Firestore Database → Create database, region eur3 (Europe), production mode. The region cannot be changed later. Creating the database also switches on the Cloud Firestore API, which the weekly export job needs.
  4. Authorised domains — Authentication → Settings → Authorised domains. Make sure your live domain is listed, otherwise the Google popup refuses to open.
  5. Deploy — from the project folder run firebase deploy. That uploads the site, the security rules and the indexes in one go.
