Qwizzy privacy control

Delete your Online account.

This permanently removes your anonymous Qwizzy Online account and its associated server data. Offline scores and settings stored only on your device are not affected.

1

Request a verification code

Enter the eight-character friend code shown in Qwizzy. Knowing this public code alone cannot delete an account.

2

Confirm in the app

Open Qwizzy on the device that owns this account. A six-digit code will appear automatically and remains valid for ten minutes.

✓

Account deleted

Your Qwizzy Online account and associated server data have been permanently removed. You may now close this page.

What is deleted?

Your anonymous Online account, profile, friend code, online matches, leaderboard data, invitations, reports, push tokens and submitted-question records linked to that account.

No longer have the app?

You can still request deletion without reinstalling Qwizzy. Email us with your friend code and player name so we can begin a manual ownership check.

Request manual deletion

Never share the six-digit verification code with anyone. Generis Data Base will never ask for it by email.
